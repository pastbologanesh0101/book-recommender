# Book Recommender

A book recommender built with **collaborative filtering** — matrix
factorization trained with stochastic gradient descent (SGD), implemented
from scratch in numpy (no scikit-learn matrix-factorization helpers).

## Collaborative filtering vs. content-based filtering

There are two classic families of recommender approaches:

- **Content-based filtering** looks at *item attributes* — genres, tags,
  descriptions, keywords — and recommends items similar to ones a user
  already liked (e.g. TF-IDF + cosine similarity over genre/tag text). It
  never looks at other users; it only needs the item's own metadata.

- **Collaborative filtering** (used here) ignores item content entirely. It
  looks only at the sparse **user x item ratings matrix** — who rated what,
  and how — and finds *latent patterns* in that matrix: groups of users who
  tend to agree, and groups of books that tend to get liked by the same
  people. It can recommend a book to you purely because people whose taste
  overlaps with yours loved it, even if you've never seen its genre before.

This project deliberately uses collaborative filtering (matrix
factorization) rather than content-based filtering, as a genuinely
different machine-learning technique from a content-based sibling project.

## The algorithm: matrix factorization via SGD

We model the (unknown, mostly-missing) full ratings matrix `R` as

```
R[u, i]  ≈  mu + b_u[u] + b_i[i] + P[u] · Q[i]
```

- `mu` — global average rating across all observed ratings
- `b_u[u]`, `b_i[i]` — per-user and per-item bias terms (some users rate
  everything higher, some books are just more beloved)
- `P` — a `n_users x n_factors` matrix; row `P[u]` is user `u`'s learned
  latent "taste" vector
- `Q` — a `n_items x n_factors` matrix; row `Q[i]` is book `i`'s learned
  latent "style" vector

Training (`MFModel.fit` in `mf.py`) only ever looks at the ratings that
actually exist. For every observed `(user, item, rating)` triple, each
epoch:

1. Predict `pred = mu + b_u[u] + b_i[i] + P[u]·Q[i]`
2. Compute the error `err = rating - pred`
3. Take an SGD step, with L2 regularization on every learned parameter:

```
b_u[u] += lr * (err        - reg * b_u[u])
b_i[i] += lr * (err        - reg * b_i[i])
P[u]   += lr * (err * Q[i] - reg * P[u])
Q[i]   += lr * (err * P[u] - reg * Q[i])
```

Regularization keeps the latent vectors from overfitting to noise in a
sparse matrix. After enough epochs, `P` and `Q` capture genuine
collaborative structure, and `P[u]·Q[i]` gives a good prediction even for
`(u, i)` pairs never observed in training — which is exactly what's needed
to recommend unrated books.

## Dataset

`data/ratings.csv` and `data/books.csv` are a synthetic dataset (50 users x
80 books, ~35% density — sparse, like real rating data) generated by
`generate_data.py`. Ratings are generated from true underlying latent
factor vectors per user/book plus per-user/per-book bias and Gaussian noise,
so the CSVs contain genuine collaborative patterns for the model to
recover — this isn't random noise.

pip install -r requirements.txt

## Usage

Train the model and see validation RMSE:

```bash
python train.py
```

Get top-5 recommendations for a user:

```bash
python recommend.py --user-id 7
```

(`recommend.py` will train a model automatically on first run if
`model.npz` doesn't exist yet.)

Run tests:

```bash
python -m pytest tests/ -v
# or: python -m unittest discover -s tests -v
```

## Cold start

Two cases are handled explicitly (see `recommend()` in `mf.py`, and tested
in `tests/test_mf.py`):

- **Unseen user** (id outside the range the model was trained on): there's
  no learned latent vector for them, so we fall back to a **popularity
  ranking** — books sorted by `mu + item_bias`, i.e. "what everyone tends to
  rate highly." This never crashes.
- **User with very few ratings** (but still present in training data): the
  model still has a (noisier) latent vector for them, so normal personalized
  prediction is used — just less confidently.
